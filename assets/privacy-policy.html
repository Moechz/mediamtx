MediaMTX for TOS — Privacy Policy

Last updated: 2026-10. This policy describes the TOS 7 package of MediaMTX.

1. Summary / 摘要

This application is a self-hosted media streaming server. It does not contain analytics, telemetry, advertising, crash reporting or any "phone home" feature. No personal data is sent to the package maintainer or to the upstream project.

本应用是自托管的流媒体服务器，不含任何统计分析、遥测、广告、崩溃上报或“回传”功能，不会向打包者或上游项目发送任何个人数据。

2. What is processed and where it stays / 处理内容与存放位置

  • Media streams published by cameras/encoders pass through the server in memory and are forwarded to readers. They can be recorded to disk only if you explicitly enable recording in /var/lib/mediamtx/mediamtx.yml. Recordings stay on your NAS.
  • Connection data (client IP address, protocol, path name, byte counters) is kept in memory for the management API and metrics and is visible to NAS administrators.
  • Logs are written to the system journal / stdout and are stored locally on your NAS.
  • Configuration and credentials are stored locally in /var/lib/mediamtx/ (including the generated publisher password file, which is readable only by the NAS administrator).

3. Network access / 网络访问

The server only receives inbound connections on your local network (RTSP/RTMP/HLS/WebRTC/SRT ports). The management API, metrics and playback listeners are bound to loopback (127.0.0.1) and are reachable only through the TOS web server gateway, which is protected by TOS account authentication. The application itself never initiates outbound connections unless you explicitly configure a feature that needs one (for example an external HTTP/JWT authentication server, a redirect/on-demand source, or a playback server).

服务器仅在本机所在局域网接收入站连接（RTSP/RTMP/HLS/WebRTC/SRT 端口）。管理 API、指标与回放服务 只监听回环地址，只能经 TOS 网页网关（受 TOS 账号认证保护）访问。除非你显式启用需要外联的功能 （如外部 HTTP/JWT 认证源、redirect/按需拉流源或回放服务器），应用自身不会主动发起外连。

4. Children / 未成年人

This is an infrastructure service; it is not directed at children and collects no personal data.

5. Changes and contact / 变更与联系

Changes to this policy will be published in the package and its public repository. Questions or requests: please open an issue at github.com/Moechz/mediamtx/issues.

MediaMTX is developed upstream by the bluenviron project (github.com/bluenviron/mediamtx, MIT). This TOS package is an independent port.
